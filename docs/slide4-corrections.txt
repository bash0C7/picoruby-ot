ARCHITECTURE COMPONENTS TO INCLUDE:

1. SerialProtocol (ruby.wasm)
   - Parses USB serial frames at 115200bps from ATOM Matrix
   - Frame format: <D:NNNN,AX:NNNN,AY:NNNN,AZ:NNNN>
   - D = distance (mm), AX/AY/AZ = accelerometer axes

2. SensorMapper (ruby.wasm)
   - distance_to_note: distance (mm) → linear mapping → MIDI note → scale snap → Hz
   - Scale snap: 4 scales selectable: pentatonic / major / minor / chromatic
   - Note-to-Hz: equal temperament, A4=440Hz  (440 * 2^((midi-69)/12))
   - accel_to_fm_depth: AX+AY+AZ magnitude → FM depth 0.0-1.0

3. PresetManager (ruby.wasm)
   - 4 presets: otamatone / clean / acid / retro
   - Each preset defined via SynthPatch DSL
   - Preset waveforms: triangle, sine, sawtooth, square (varies by preset)

4. SynthPatch DSL (ruby.wasm)
   - Ruby DSL running in browser via ruby.wasm
   - Defines FM carrier + FM modulator + filter + gain chain
   - Serializes to JSON → calls JS.global.synthPatchBuild(json)

5. FM Synthesis (Web Audio API / JS)
   - carrier OscillatorNode frequency ← modulator OscillatorNode via GainNode (depth)
   - Modulator connects to carrier.frequency AudioParam (not audio output)
   - Smooth glide via setTargetAtTime (50ms time constant, theremin-style)

6. Web Audio signal chain (JS)
   - OscillatorNode (carrier) → BiquadFilterNode → GainNode → AnalyserNode → destination

7. Canvas Visualization (JS)
   - ocanvas: Oscilloscope (time domain, zero-crossing stabilized)
   - lcanvas: Level meter (RMS dBFS, peak hold, color gradient)
   - gcanvas: Synth patch graph (clickable nodes, node editor)

8. ruby.wasm runtime
   - @ruby/4.0-wasm-wasi 2.8.1
   - Same Ruby syntax runs in Chrome — reproducible at home without hardware
